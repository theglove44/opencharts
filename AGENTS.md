# OpenCharts

- Browser chart app for market candles, indicators, drawings, and multiple symbols.
- Use `pnpm install` then `pnpm dev` to run it.
- Use `pnpm test`, `pnpm lint`, and `pnpm build` after changes.
- Keep the default local mock data working for safe development.
- Keep API keys and local environment files out of commits.
- Check chart behaviour in the browser after interface changes.
